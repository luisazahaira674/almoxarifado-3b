# almoxarifado-3b
Sistema de almoxarifado para o SENAI feito pela turma tercetroia

## Objetivos do projeto:
Este sistema foi desenvolvido na disciplina de Implantacao de Sistemas do SENAI. O objetivo e controlar o estoque de materiais de TI e escritorio da instituicão., registrando entradas, saidas e gerando alertas de estoque baixo.
